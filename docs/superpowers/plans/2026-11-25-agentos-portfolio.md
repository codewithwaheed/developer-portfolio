# AgentOS Portfolio Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the Gatsby portfolio with AgentOS, a premium glass desktop OS in the browser where an AI agent (scripted intents first, Gemini free tier as fallback) drives the UI.

**Architecture:** Next.js App Router app. Content stays as markdown in `content/` and is read server-side at build. The homepage server-renders all core content as semantic HTML, then the client OS (Zustand window manager, Motion springs) takes over. The agent turns questions into a list of `AgentAction`s that one executor animates; scripted intents produce them locally, the `/api/agent` route gets them from Gemini through the Vercel AI SDK, guarded by a Supabase-backed store for rate limits, cache and question log.

**Tech Stack:** Next.js 15 (App Router, TypeScript), React 19, Tailwind CSS v4, `motion` (Framer Motion), `zustand`, `gray-matter` + `unified`/`remark`/`rehype` + `rehype-pretty-code` (shiki), `ai` + `@ai-sdk/google`, `@supabase/supabase-js`, `geist` fonts, Vitest + Testing Library, Playwright. Package manager: npm. Hosting: Vercel.

**Spec:** `docs/superpowers/specs/2026-11-25-agentos-portfolio-design.md`

## Global Constraints

- Node 22 LTS (`.nvmrc` = `22`); npm, `package-lock.json` committed, `yarn.lock` removed.
- Gemini API key, Supabase service key and IP salt exist only in server env vars; nothing under `NEXT_PUBLIC_`.
- Env vars (all in `.env.example`): `GEMINI_API_KEY`, `GEMINI_MODEL`, `SUPABASE_URL`, `SUPABASE_SERVICE_ROLE_KEY`, `IP_HASH_SALT`, `AGENT_VISITOR_CAP=5`, `AGENT_DAILY_CEILING`, `CRON_SECRET`.
- `GEMINI_MODEL`: the Flash model with the highest free requests-per-day shown in Google AI Studio's rate-limit page at build time. `AGENT_DAILY_CEILING` = that RPD minus 10%.
- Per-visitor cap: 5 Gemini questions per 24 hours, keyed by salted SHA-256 of the IP. Raw IPs are never stored.
- Answer cache and rate-limit rows expire after 24 hours. The question log is never deleted; it stores no IP or identifier.
- No visitor-facing privacy/"powered by" notice in the prompt bar.
- No Apple icons, Apple logo, traffic-light window buttons or Apple wallpapers. Window controls are AgentOS's own (rounded squares).
- Quota fallback copy (exact): `My neural core is cooling down. Here's what I can show you right now:` followed by the scripted suggestion chips.
- `prefers-reduced-motion`: no boot animation, no cursor travel, windows appear instantly, sound muted.
- Desktop shell at viewport width ≥ 768px; AgentOS Mobile below 768px.
- Content copy is unchanged except the new frontmatter fields `tags` and (featured) `company`.
- Window resizing is out of scope for v1.

## Review Focus

1. Visitor clicks or types while the agent is mid-plan: the plan stops at the next step and the visitor's action wins (test in Task 9).
2. Gemini returns tool calls with unknown app ids, project ids or post slugs, or malformed args: those actions are dropped, the rest run, nothing throws (tests in Tasks 9 and 12).
3. Supabase unreachable, Gemini 429, or daily ceiling reached: `/api/agent` answers 200 with a fallback payload, never 500, and the site keeps working on scripted intents (test in Task 12).
4. Empty, whitespace-only or very long questions: empty is ignored client-side; the server rejects over 500 characters with 400 (tests in Tasks 10 and 12).
5. `localStorage` unavailable (private mode, blocked storage): memory, mute, theme and boot-skip fall back to in-memory defaults without throwing (test in Task 3's `safeStorage`).
